## Summary of Changes
1. **Modal Elimination**:
   - Removed `showUserModal` overlay popup from `src/pages/OperatorManifest.jsx`.
   - Replaced modal flow with an inline **Pending User Registrations Table** rendered directly on the page.

2. **Pending Users Table List**:
   - Fetches registered auth users awaiting staff role assignment.
   - Includes real-time pending user counter badge.
   - Interactive role selection dropdown (`Volunteer (Check-in)` vs `Administrator (Full)`).
   - 1-click **Approve Staff Access** button.
   - Manual "Add Custom Staff" expandable drawer for bypassing signup screen when needed.

3. **Active Staff Table List**:
   - Upgraded active staff display into a sleek, high-density table.
   - Display columns: `Staff Member (Avatar & Role)`, `Email Address`, `Assigned Role`, `Access Status (Active/Revoked)`, `Actions`.
   - Action controls: Reset Password Link dispatch, Access Toggle (Grant/Revoke), Remove Staff profile.
   - Integrated Search & Role Filter bar (`All`, `Admin`, `Volunteer`).
